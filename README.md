# opengramm

Проверка текста из любого поля: горячая клавиша → окно у курсора → LanguageTool сразу, LLM (OpenRouter) по кнопке.

## Использование

1. Выделите текст в любом приложении (или скопируйте его) и нажмите `Ctrl+Alt+G`.
2. Замечания LanguageTool приходят сразу; при правке текста в окне проверка повторяется через 0.8 с после паузы.
3. Кнопки тона/стиля или своя инструкция отправляют текст в LLM.
4. `Ctrl+Enter` копирует результат и закрывает окно, `Esc` закрывает.

Откуда берётся текст: выделение (UI Automation) → всё поле → буфер обмена.

## Приватность

- Поля паролей и приложения из `blocklist` не читаются, буфер обмена для них тоже.
- В LanguageTool текст уходит автоматически (сейчас публичный `api.languagetool.org`, для локального сервера поменяйте `lt_url`).
- В OpenRouter текст уходит только по кнопке.

## Настройки

Трей → «Настройки»: `%APPDATA%\dev.opengramm.app\config.json`. Изменения применяются после перезапуска.
Ключ: `openrouter_key` в конфиге или переменная окружения `OPENROUTER_API_KEY`.

## Сборка

```bat
cargo build --release
```

Если линкер пишет `cannot open file 'msvcrt.lib'` (Rust выбрал VS без десктопных библиотек), собирайте из окружения Build Tools:

```bat
"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat" && cargo build --release
```
