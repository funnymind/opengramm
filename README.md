# opengramm

Проверка текста из любого поля: горячая клавиша → окно у курсора → LanguageTool сразу, LLM (OpenRouter) по кнопке.

## Использование

- **Автопроверка:** печатаете в любом поле, после паузы 1.5 с у каретки появляется плашка с числом ошибок и подчёркнутыми словами. Клик открывает окно, ✕ или правый клик скрывает.
- `Ctrl+Alt+H` — та же плашка по запросу (показывает и «Ошибок нет»).
- `Ctrl+Alt+G` — большое окно: замечания LanguageTool с вариантами замены, подчёркивания в тексте, переписывание через LLM (тон, стиль, своя инструкция). `Ctrl+Enter` копирует результат и закрывает окно, `Esc` закрывает.

Откуда берётся текст: выделение (UI Automation) → всё поле (для длинных документов в автопроверке — абзац под кареткой) → буфер обмена (только по горячей клавише).
В терминале (Windows Terminal, консоль) берётся строка под курсором без промпта.

Автопроверка не нагружает систему: хук клавиатуры запоминает только время нажатия, проверка идёт одна на паузу, повторный текст не отправляется, запросов не больше одного в 3 с.

## Приватность

- Поля паролей и приложения из `blocklist` не читаются, буфер обмена для них тоже.
- В LanguageTool текст уходит автоматически, в том числе при автопроверке (сейчас публичный `api.languagetool.org`, для локального сервера поменяйте `lt_url`; выключить автопроверку: `auto_check: false`).
- Хук клавиатуры не сохраняет, какие клавиши нажаты, только время последнего нажатия.
- В OpenRouter текст уходит только по кнопке.

## Настройки

Трей → «Настройки»: `%APPDATA%\dev.opengramm.app\config.json`. Изменения применяются после перезапуска.
Ключ: `openrouter_key` в конфиге или переменная окружения `OPENROUTER_API_KEY`.

## Сборка

Установщик (NSIS) и exe в `target/release`:

```bat
npx @tauri-apps/cli build
```

Если линкер пишет `cannot open file 'msvcrt.lib'` (Rust выбрал VS без десктопных библиотек), собирайте из окружения Build Tools:

```bat
"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat" && npx @tauri-apps/cli build
```
